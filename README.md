Slack Bot with humor

My slack bot which I've made on VS Code and have linked to the Slack Channel, It works well.

My slack bot has the bot pings:

* You can use /sai-bot-ping, to get a latency update.
* You can use /sai-bot-catfacts, to get a fact on a cat.
* You can use /sai-bot-joke, to hear a joke.

It is running 24/7 through the help of Hackclub's Nest!
*You can test out the bot in Slack->Hackclub->bot-spam (or any other channel, you have permissions to use)

Spent around a week(including waiting period for Nest approval) building the Hackpad.

Ouputs(these are just examples, you will get a different output each time!) for each of the pings: 
i)/sai-bot-ping: Pong!
                  Latency: 0ms
                  
ii)/sai-bot-catfacts: Cat Fact:
                       A cat will tremble or shiver when it is in extreme pain

iii)/sai-bot-joke: What are the strongest days of the week:
                   Saturday and Sunday... the rest are weekdays.
