Slack Bot with humor

My slack bot which I've made on VS Code and have linked to the Slack Channel, It works well.
My slack bot has the features:
* You can use /sai-bot-ping, to get a latency update.
* You can use /sai-bot-catfacts, to get a fact on a cat.
* You can use /sai-bot-joke, to hear a joke.

It is running 24/7 through the help of Hackclub's Nest!
*You can test out the bot in Slack->Hackclub->bot-spam (or any other channel, you have permissions to use)
